How to start contributing

  1. Read the project's README file.
  2. Check the contribution guidelines.
  3. Explore issues labelled good first issue.
  4. Fork the repository on GitHub.
  5. Clone your fork and create a new branch.
  6. Make your changes and test them.
  7. Submit a Pull Request for review.

Contribution instructions can differ between repositories. Always follow the project's own guidelines.
